# TinySense / TinySense+

Shared project page for TinySense and its entropy-aware extension TinySense+.

**Website:** https://phucngvinuni.github.io/TinySense/

- **TinySense (IEEE PerCom 2026):** https://arxiv.org/abs/2601.15838
- **TinySense+ (preprint):** https://www.alphaxiv.org/pdf/2610.tinysense-entropy-aware-wifi-sensing
- **TinySense code:** https://github.com/Toandinh1/TinySense-PerCom2026
- **TinySense+ code:** https://github.com/phucngvinuni/TinySensePlus

## Update the page

Edit `index.html` for content, `style.css` for layout, and `app.js` for citation and prefix interactions. Figures are in `assets/`. GitHub Pages serves the root of the `main` branch; pushing changes updates the website.

For local preview, run `python -m http.server 8765` and open http://localhost:8765.

## Research content

The page preserves separate author lists and paper links. TinySense+ is labeled as a preprint. The results selector displays only the reported MM-Fi ablation settings; it does not run a model or interpolate new results. Figures are rendered from the corresponding author manuscript figures; research and figure rights remain with their respective owners.

The site was inspired by the academic structure of https://phucngvinuni.github.io/FISHER/ . The page implementation was written for this project.
